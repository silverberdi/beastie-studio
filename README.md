# Beastie Studio

**Descubrir. Pensar. Compartir.**  
**Juegos hechos con cariño.**

Sitio institucional y catálogo del estudio independiente **Beastie Studio** (singular). El sitio presenta juegos, artículos y formas voluntarias de apoyar el proyecto. **No** contiene ni reconstruye los motores de los juegos.

## Estado y autoridad
Este repositorio comienza como contexto de producto y diseño, **no como implementación**. La ejecución debe realizarla Mini Me mediante issues autorizados y el flujo nativo de OpenSpec. PR y merge humanos. No publicar ni configurar cobros sin aprobación.
