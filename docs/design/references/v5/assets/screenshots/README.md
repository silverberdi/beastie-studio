# Beastie Studio — Capturas reales v1

Este paquete contiene **capturas reales** de los juegos suministradas por el usuario para usar en la referencia V5 y en la implementación del sitio.

## Estructura
- `multiplo/`: 4 capturas reales de Múltiplo
- `boxio/`: 3 capturas reales de Boxio
- `manifest.json`: hashes SHA-256, tamaños y rutas

## Uso recomendado
- Usar al menos **1 screenshot principal por juego** en el catálogo.
- Mantener disponibles las demás capturas para fichas de detalle (`/juegos/[slug]`) y/o carrusel secundario.
- No sustituir estas capturas por ilustraciones inventadas.

## Sugerencia de screenshot principal
- Múltiplo: `multiplo/multiplo-pregunta-1.webp`
- Boxio: `boxio/boxio-partida-local.webp`
