# Referencias visuales — Beastie Studio

Carpetas versionadas por dirección de diseño:

- [`legacy/`](legacy/README.md): referencias originales de Stitch, conservadas sin alterar contenido ni hashes. No son el diseño vigente.
- [`v5/`](v5/README.md): **dirección visual V5.4 aprobada**. Inicio y Juegos con hero a ancho completo, contorno marfil y efecto parallax.

**Fuente de verdad para implementación:** documentación de V5.4, assets finales versionados y capturas reales de los juegos. No utilizar los HTML de referencia como sustitutos directos de componentes Astro.

Para comenzar desarrollo, comprobar que están presentes los dos WebP definitivos y las capturas reales de los juegos; no inventar sustitutos.
