# Contrato de ejecución de agentes — Beastie Studio

Lee README.md y docs/ antes de modificar código. Este repositorio contiene el sitio corporativo y catálogo de Beastie Studio, no los juegos.

- Ejecutar únicamente issues dirigidos a Mini Me y **SIN** etiqueta `disabled`.
- `disabled` significa **NO ejecutar con Mini Me**, aunque la descripción incluya tareas técnicas.
- El proyecto debe usar OpenSpec nativo para proponer, aplicar y verificar cambios. Evitar workflows ad hoc que simulen OpenSpec.
- No abrir PR o publicar en producción por mero hecho de ver documentación.
- No cambiar branding, inventar logos/links/datos de pago, ni asumir funciones no confirmadas.
- No tocar repositorios Múltiplo o Boxio desde esta ejecución.
- No desplegar salvo issue explícito y aprobación.
- Mantener Astro estático, componentes simples, sin servidor o CMS innecesario.
- Toda propuesta de cambio pasa por PR con merge humano.
- Si falta un asset o dato de pago, registrar dependencia clara y dejar placeholder no accionable, nunca fabricar un valor.

- Fuente visual única para ejecución: `docs/design/references/README.md` y archivos locales allí enumerados. **No acceder a Stitch ni depender de enlaces a Stitch**.
